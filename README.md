# AI 101

人文社科大学生 AI 入门 101。面向人文社科学习与研究的 AI 入门指南，欢迎共同讨论、修订与更新。

## 文件

- [AI-101.md](AI-101.md)：最新 v2 原稿，是内容维护的基准。
- [index.html](index.html)：完整单文件网页，内含样式和交互；下载后双击即可离线阅读。
- [CONTRIBUTING.md](CONTRIBUTING.md)：共创与修订约定。

## 阅读与更新

GitHub 可直接阅读 Markdown。浏览网页时，请下载 index.html 后用浏览器打开；GitHub 文件预览不会执行网页。

修改内容时先更新 AI-101.md，再同步 index.html 的正文、目录与篇章跳转。网页中的加粗、高亮和下划线仅用于阅读提示，不能改变原文语义。注意保留代码块、链接和结语。

目前个人网站展示地址：https://jinhuazhang.top/portfolio/ai-101

本仓库与个人网站分别维护；推送本仓库不会自动更新个人网站，也不会自动部署 GitHub Pages。
